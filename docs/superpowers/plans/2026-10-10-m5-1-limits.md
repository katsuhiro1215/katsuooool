# M5-1 画像ツールの上限の見直し 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 枚数上限を無料10枚・Premium20枚（AVIF 出力は無料2・Premium5）に引き上げ、2,500万画素の画像でも `app` コンテナがメモリ不足で落ちないようにし、HEIC（iPhone の写真）を画像形式変換の入力に加える。

**Architecture:** 上限値を `config/image_tools.php` に集約し、`ImageToolLimits` ヘルパー経由で各コントローラーが読む。Imagick のリソース制限は `ImagickLimits` が起動時に設定する。サーバー側（PHP・内側 Caddy）の上限とタイムアウトは `Dockerfile.prod`・`Caddyfile.prod` で引き上げる。

**Tech Stack:** Laravel 13 / Pest、Intervention Image（Imagick ドライバー）、Vue 3 + TypeScript + Vitest、Docker（php:8.4-fpm-alpine、caddy）。

**Spec:** `docs/superpowers/specs/2026-10-10-m5-1-limits-design.md`

## Global Constraints

- ドキュメント・コメントは日本語。
- 枚数：無料 10・Premium 20。AVIF 出力：無料 2・Premium 5。1ファイル 10MB（10 * 1024 * 1024）。画素数 25,000,000（Task 6 の結果で見直す場合は台帳に Ruling を残す）。
- `post_max_size` 230M、`max_file_uploads` 25、内側 Caddy `request_body max_size` 230MB、`read_timeout` と PHP `max_execution_time` は 300 秒。
- `mem_limit: 512m`（`app`）は、Task 6 の結果で必要になったときだけ変更する。変更するときは、本体を巻き込まない範囲（インスタンスの空き約 2GB）で、台帳に Ruling を残す。
- 本番サーバーの操作はこの計画に含めない（実装後、オーナー確認のうえ別手順）。
- `composer test`（Pint・PHPStan・Pest）と `npx vitest run`、`npm run lint`、`npm run types:check` が通ること。
- 「CLI バイナリに依存しない」方針は維持する（cwebp・pngquant は M5-2）。

## Review Focus

- 無料で10枚ちょうど・11枚（超過）、Premium で20枚・21枚（Task 2 のテスト）。
- AVIF 出力のとき、無料2枚は通り3枚は 422、Premium 5枚は通り6枚は 422（Task 3 のテスト）。同じ3枚でも WebP なら通る。
- フロントの案内文が、無料の上限10枚で消えない（Task 4 のテスト）。以前は `maxFiles < 10` で判定していた。
- HEIC（`image/heic`）の入力が通り、`getimagesize` が失敗しても画素数チェックが効く。HEIC を圧縮など他ツールに渡すと「対応していない形式」として拒否される（Task 5 のテスト）。
- 25MP の JPEG・PNG・WebP が、512MB のコンテナで強制終了しない（Task 6・8 の実測）。

画素数チェックの `getimagesize` が HEIC では `false` を返す。private メソッドを追加し、呼び出しを置き換える:

```php
    /**
     * @return array{0: int, 1: int}|null
     */
    private function readDimensions(string $path): ?array
    {
        $size = getimagesize($path);

        if ($size !== false) {
            return [$size[0], $size[1]];
        }

        // HEIC など getimagesize が読めない形式は Imagick のヘッダー読み取りで調べる（デコードしない）
        if (! class_exists(\Imagick::class)) {
            return null;
        }

        try {
            $imagick = new \Imagick;
            $imagick->pingImage($path);
            $dimensions = [$imagick->getImageWidth(), $imagick->getImageHeight()];
            $imagick->clear();

            return $dimensions;
        } catch (\ImagickException) {
            return null;
        }
    }
```

`process()` の中の次のブロックを置き換える:

```php
                $dimensions = $this->readDimensions($inputAbsolutePath);

                if ($dimensions === null) {
                    throw new RuntimeException('Failed to read image dimensions.');
```

`app/Support/ImagickLimits.php`:

```php
<?php

namespace App\Support;

use Imagick;

class ImagickLimits
{
    private const TYPES = [
        'memory' => 'RESOURCETYPE_MEMORY',
        'map' => 'RESOURCETYPE_MAP',
        'disk' => 'RESOURCETYPE_DISK',
        'thread' => 'RESOURCETYPE_THREAD',
    ];

    /**
     * 大きな画像で app コンテナがメモリ不足になるのを防ぐ。
     * 上限を超えた分は、メモリではなくディスクのキャッシュに逃がされる。
     */
    public static function apply(): void
    {
        if (! class_exists(Imagick::class)) {
            return;
        }

        foreach (self::TYPES as $key => $constant) {
            $value = config("image_tools.imagick.{$key}");

            if ($value !== null) {
                Imagick::setResourceLimit(constant(Imagick::class.'::'.$constant), (int) $value);
            }
        }
    }
}
```

`app/Support/ImageProcessingGate.php`:

```php
<?php

namespace App\Support;

use App\Exceptions\Tools\ProcessingBusyException;

class ImageProcessingGate
{
    /**
     * 重い画像処理の同時実行数を制限する。php-fpm が複数の処理を同時に受けても、
     * メモリが重なって app コンテナが落ちないようにする。
     */
    public static function run(callable $work): mixed
    {
        $slots = max(1, (int) config('image_tools.concurrency', 2));

        for ($i = 0; $i < $slots; $i++) {
            $handle = fopen(storage_path("framework/image-gate-{$i}.lock"), 'c');

            if ($handle !== false && flock($handle, LOCK_EX | LOCK_NB)) {
                try {
                    return $work();
                } finally {
                    flock($handle, LOCK_UN);
                    fclose($handle);
                }
            }

            if ($handle !== false) {
                fclose($handle);
            }
        }

        throw new ProcessingBusyException('All image processing slots are busy.');
    }
}
```

`config/image_tools.php` に追加: `'concurrency' => 2,`
