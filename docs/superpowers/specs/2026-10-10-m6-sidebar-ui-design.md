# M6: 左サイドバー付き UI への改修 設計書

作成日: 2026-10-10 / ブランチ: `feature/m6-sidebar-ui` / 対象: ロードマップ M6

## 1. 目的

カテゴリを左サイドバーに置き、右のメインにそのカテゴリのツールを並べる画面にする（参考: Color Hunt）。ツール画面を開いてもサイドバーは出したままにし、カテゴリ間を行き来しやすくする。

## 2. 合意事項（オーナー確認済み）

- サイドバー＝カテゴリ、メイン＝ツールのカード一覧。ツールを開くとメインがツール画面に切り替わり、サイドバーは出したまま。
- サイドバーは**常に表示**（畳む機能は作らない）。
- 順番は M6（本件）→ M5（画像）→ M8（色）。新しい画面を最初から新レイアウトの上に作るため。

## 3. 現状

- ツール画面（約45ページ）はすべて `layouts/Public/PublicLayout.vue`（ヘッダー＋フッター）を使う。
- ツールは49個、カテゴリは8つ（`config/tools.php` の `category`）。
- トップ `Home.vue` が検索窓・カテゴリのピル型タブ・4列カードを持つ。ツール一覧（`tools`）は `HomeController` が Home にだけ渡している。
- カテゴリ定義（`CATEGORY_TABS`）とフィルタ（`filterTools`）は `resources/js/lib/toolFilter.ts`。

## 4. 設計

### 4.1 レイアウト

- `PublicLayout.vue` に左サイドバーを組み込む。ヘッダーとフッターはそのまま。各ツール画面のファイルは変更しない。
- lg（1024px）以上: 幅 240px の固定サイドバー。メインは残りの幅。
- lg 未満: ヘッダー下の「カテゴリ・検索」ボタンで開閉するパネル（オーバーレイにはしない）。
- 管理画面（`AdminLayout`）、認証画面、設定画面は対象外。

### 4.2 サイドバーの中身（新規 `components/Public/CategorySidebar.vue`）

- 上から、ツール検索窓、「すべて」、各カテゴリ（件数バッジ付き）。
- 現在のカテゴリを強調表示する。トップでは URL の `category`、ツール画面では、現在のパスと一致するツールの `category`。
- 検索窓に入力して Enter すると `/?q=…` に移動し、メインに結果を出す。入力中のライブ絞り込みはしない（URL で共有でき、実装が一本になる）。

### 4.3 メイン（トップ `Home.vue`）

- カテゴリは URL クエリ `?category=image` で持つ（共有・戻る操作に対応）。未指定は「すべて」。
- ピル型タブは廃止（サイドバーに移る）。検索窓もサイドバーに移す。
- カード一覧は、サイドバー分だけ狭くなるので `xl` で4列→3列とする。
- `PremiumBanner`・`WebsiteStarterBanner` はこれまでどおりカード一覧の下に置く。

### 4.4 データの渡し方

- サイドバーは全ページで必要なため、`HandleInertiaRequests` の共有プロパティに `toolNav`（各ツールの `slug`・`name`・`category`・`href` のみ。説明文は含めない）を追加する。
- 件数バッジと現在カテゴリの判定は、この `toolNav` からフロントで算出する。
- `HomeController` が渡す `tools`（説明文つき）は Home で引き続き使う。

### 4.5 コードの整理

- カテゴリ定義は `toolFilter.ts` の `CATEGORY_TABS` を流用し、名前は変えない（参照3箇所で、改名の利益が小さい）。
- `filterTools` は維持する。

## 5. やらないこと

- サイドバーを畳む機能、ツール名の展開表示、お気に入り、最近使ったツール。
- 管理画面・認証・設定画面のレイアウト変更。
- 各ツール画面の内部デザイン変更。

## 6. エラー・境界

- 未知の `category`: 「すべて」として扱う。
- 該当ツールなし: これまでどおり「該当するツールが見つかりませんでした。」を出す。
- ツール画面でも一覧にない URL（お問い合わせ、ブログ、規約など）: どのカテゴリも強調しない。サイドバーは出す。
- JS 無効・SSR は現状どおり（Inertia のみ）。

## 7. テスト

- Vitest: `CategorySidebar`（件数、現在カテゴリの強調、検索の遷移）、`toolFilter`。既存の `PublicHeader`・`PublicFooter` のテストを壊さない。
- Pest: `toolNav` が全ページの共有プロパティに入ること、`/?category=image` が画像ツールだけを返す表示になること。
- `composer test`（Pint・PHPStan・Pest）と `npm run lint`、Vitest を通す。
- ブラウザ確認（Playwright）: デスクトップ幅とモバイル幅で、トップ、画像ツール、問い合わせページ。
